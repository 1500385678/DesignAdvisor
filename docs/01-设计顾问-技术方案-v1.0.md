## 一、项目概述

### 1.1 愿景

> **让每个设计师身边都有一位"原研哉 + 一位 Don Norman + 一位 IDEO 合伙人"。**

把张勇已经整理的"设计基础 → 设计思维 → 用户体验 → 视觉设计 → 交互设计 → 产品设计 → 服务设计"完整知识图谱，做成一个**会思考的设计顾问**——能讲理论、能评作品、能给方法、能跨学科，也能针对一个设计问题给出"理论 + 方法 + 案例"三件套。

### 1.2 形态

| 形态 | 场景 | 状态 |
|------|------|------|
| **飞书 Agent（当前）** | 工作中随问随答 | ✅ 已上线 |
| **Web App（核心）** | 设计师/产品/创作者 | ⏳ 规划中 |
| **桌面端（Electron/Tauri）** | 设计工具 | 📋 远期 |
| **微信小程序** | 设计启蒙 | 📋 远期 |
| **REST API** | 嵌入 Figma/Sketch | 📋 远期 |
| **Figma 插件** | 实时设计评估 | 📋 远期 |

### 1.3 已有资产盘点

| 资产 | 位置 | 价值 |

## 二、产品定位

### 2.1 目标用户

| 用户群 | 痛点 | 价值 |
|--------|------|------|
| **设计学生** | 抽象、缺方法 | 理论 + 案例 + 工具 |
| **平面设计师** | 缺灵感、缺理论 | 视觉原则 + 经典库 |
| **UX/UI 设计师** | 不会研究、不会评 | 用户研究 + 可用性 |
| **产品经理** | 不会做产品设计 | 产品思维 + MVP |
| **交互设计师** | 缺模式库 | 交互模式 + 微交互 |
| **服务设计师** | 缺方法 | 服务设计 + 旅程图 |
| **设计爱好者** | 想系统补课 | 知识图谱 + 案例 |

### 2.2 核心价值主张

1. **设计三件套讲解**：选问题 → 同时输出"理论 + 方法 + 案例"
2. **AI 设计评估**：上传作品 → 多维度评估 + 改进建议
3. **AI 设计助手**：基于需求 → 设计方案 + 草图描述
4. **AI 配色 / 排版**：基于品牌/情感 → 配色 + 排版建议
5. **设计模式库**：交互模式 + 微交互 + 经典布局
6. **跨学科桥接**：设计 ↔ 心理/商业/技术/艺术

### 2.3 差异化（vs 现有产品）

- **设计类图书**：纯文字，缺工具
- **Behance / Dribbble**：作品展示，缺教学
- **Coursera 设计课**：英文为主，互动弱
- **Figma Community**：模板型，缺理论
- **各家 SaaS**：单点工具，缺方法论

**我们的差异**：以张勇的**结构化知识图谱 + 案例库 + 工具库**为骨架，AI 提供"理论 + 方法 + 案例"三件套，覆盖基础/思维/UX/视觉/交互/产品/服务全维度。

## 三、功能架构

### 3.1 五大核心模块

```
┌─────────────────────────────────────────────────┐
│          设计顾问 DesignAdvisor                 │
├──────────┬──────────┬──────────┬────────┬───────┤
│ 知识图谱 │ 案例库   │ 工具集   │ 智能讲解│ 多端  │
│ (Graph)  │ (Case)   │ (Tool)   │ (AI)   │ (UI)  │
├──────────┴──────────┴──────────┴────────┴───────┤
│              数据层 (SQLite / PG)               │
├─────────────────────────────────────────────────┤
│              内容层 (Markdown + JSON + 图像)     │
└─────────────────────────────────────────────────┘
```

### 3.2 模块拆分

#### 模块 1：知识图谱（Knowledge Graph）
- **数据结构**：节点（知识点）+ 边（前置 / 衍生 / 案例关联）
- **覆盖**：基础 → 思维 → UX → 视觉 → 交互 → 产品 → 服务
- **节点属性**：
  - name, level, difficulty, tags, prerequisites
  - cases[]（关联案例）
  - tools[]（关联工具）
  - patterns[]（关联模式）
  - cross_refs[]（跨学科桥接）
  - applications[]（应用场景：UI/平面/产品/品牌）
  - explanation[]（三件套讲解：理论/方法/案例）

#### 模块 2：案例库（Case Library）
- **1000+ 经典案例**：
  - 品牌：苹果/无印良品/星巴克/海底捞
  - 数字产品：微信/iOS/淘宝/Airbnb
  - 工业：博朗/戴森/宜家
  - 服务：Disney/Netflix/海底捞
  - 平面：包豪斯/瑞士/日本/极简
  - 经典设计师：原研哉/Rams/Paula Scher
- **每条案例**：背景 / 策略 / 过程 / 反思

#### 模块 3：工具集（Tools）
- **50+ 工具/模板**：
  - 设计思维：5 阶段模板 / 双钻 / 同理心地图
  - 用户研究：用户访谈 / 问卷 / 可用性测试
  - 视觉：网格系统 / 配色 / 字体规范
  - 交互：模式库 / 微交互 / 反馈
  - 产品：MVP / 用户故事 / 用户旅程
  - 服务：触点 / 旅程 / 蓝图
- **每条工具**：结构 / 步骤 / 适用场景

#### 模块 4：智能讲解（AI Tutor）
- **三件套讲解**：选问题 → 同时输出"理论 + 方法 + 案例"
- **AI 设计评估**：上传作品 → 多维度评估（可用性/视觉/品牌/可访问性）+ 改进建议
- **AI 设计助手**：基于需求 → 设计方案 + 草图描述
- **AI 配色 / 排版**：基于品牌/情感 → 配色 + 排版建议
- **AI 用户研究**：基于用户描述 → 访谈问题 + 假设
- **跨学科桥接**：设计 ↔ 心理/商业/技术/艺术

#### 模块 5：多端 UI
- Web App（核心）：响应式设计，PC / 平板 / 手机
- 飞书机器人：消息形态（当前）
- 小程序：设计启蒙 + 配色工具
- 桌面端：设计工具 + 评估
- Figma 插件（远期）：实时设计评估

## 四、技术架构

### 4.1 整体架构

```
┌─────────────────────────────────────────────┐
│  表现层 (Presentation)                       │
│  Web (React/Vue) · 小程序 · 飞书 Bot · CLI  │
└──────────────────┬──────────────────────────┘
                   │ HTTPS / WebSocket
┌──────────────────┴──────────────────────────┐
│  API 层 (FastAPI · Python)                  │
│  /graph /case /tool /ai /user              │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────┴──────────────────────────┐
│  服务层 (Services)                          │
│  图谱引擎 · 案例库 · 工具集 · AI 引擎       │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────┴──────────────────────────┐
│  数据层 (Data)                              │
│  PostgreSQL · Redis · 向量库 · 文件存储     │
└─────────────────────────────────────────────┘
```

### 4.2 技术栈选型

| 层 | 选型 | 理由 |
|----|------|------|
| **后端框架** | FastAPI（Python） | 异步、自动文档 |
| **前端** | React + TypeScript | 组件丰富 |
| **UI 库** | Ant Design / shadcn/ui | 中文友好 / 现代 |
| **图像识别** | CLIP / 自研 CNN | 设计评估 |
| **配色** | culori / chroma-js | 色彩理论计算 |
| **图表** | ECharts / D3.js | 网格、可视化 |
| **数据库** | PostgreSQL（主） + SQLite（离线） | 张勇已有 SQLite 经验 |
| **缓存** | Redis | 案例库缓存、AI 响应缓存 |
| **向量库** | pgvector / Chroma | 案例检索、相似设计 |
| **LLM** | Claude / GPT / 本地 Ollama | 评估 / 方案 / 配色 / 用户研究 |
| **部署** | Docker Compose → K8s | 单机起步，平滑扩容 |
| **CI/CD** | GitHub Actions | 自动化 |
| **监控** | Sentry + Prometheus | 错误 + 性能 |
| **认证** | JWT + 飞书 OAuth | 飞书用户无缝 |

### 4.3 数据架构

#### 核心表

```sql
-- 知识点表
CREATE TABLE knowledge_points (
  id SERIAL PRIMARY KEY,
  name TEXT NOT NULL,
  level TEXT,                   -- 入门/进阶/专业
  difficulty INT,               -- 1-5
  description TEXT,
  cases JSONB,
  tools JSONB,
  patterns JSONB,
  cross_refs JSONB,
  applications JSONB,
  explanation JSONB,            -- 三件套讲解
  prerequisites INT[],
  tags TEXT[]
);

-- 案例
CREATE TABLE design_cases (
  id SERIAL PRIMARY KEY,
  title TEXT,
  designer TEXT,
  company TEXT,
  category TEXT,                -- 品牌/数字/工业/服务/平面
  year INT,
  background TEXT,
  strategy JSONB,
  process JSONB,
  reflection TEXT,
  image_url TEXT,
  knowledge_ids INT[]
);

-- 工具
CREATE TABLE design_tools (
  id SERIAL PRIMARY KEY,
  name TEXT,
  category TEXT,                -- 思维/研究/视觉/交互/产品/服务
  description TEXT,
  structure JSONB,
  steps JSONB,
  example JSONB,
  when_to_use TEXT,
  knowledge_ids INT[]
);

-- 模式库
CREATE TABLE design_patterns (
  id SERIAL PRIMARY KEY,
  name TEXT,
  category TEXT,                -- 交互/微交互/布局/导航
  description TEXT,
  use_cases JSONB,
  examples JSONB,
  when_to_use TEXT,
  anti_patterns JSONB
);

-- 设计评估
CREATE TABLE design_reviews (
  id SERIAL PRIMARY KEY,
  user_id INT,
  image_url TEXT,
  usability_score REAL,
  visual_score REAL,
  brand_score REAL,
  accessibility_score REAL,
  issues JSONB,
  suggestions JSONB,
  created_at TIMESTAMP
);

-- 用户研究
CREATE TABLE user_researches (
  id SERIAL PRIMARY KEY,
  user_id INT,
  product TEXT,
  persona JSONB,
  interview_questions JSONB,
  hypotheses JSONB,
  findings TEXT,
  created_at TIMESTAMP
);

-- 配色方案
CREATE TABLE color_palettes (
  id SERIAL PRIMARY KEY,
  user_id INT,
  name TEXT,
  mood TEXT,                    -- 情感
  colors JSONB,                 -- 颜色列表
  usage JSONB,
  accessibility_score REAL,     -- WCAG
  created_at TIMESTAMP
);

-- 题目
CREATE TABLE questions (
  id SERIAL PRIMARY KEY,
  knowledge_id INT REFERENCES knowledge_points(id),
  type TEXT,
  difficulty INT,
  content TEXT,
  answer TEXT,
  analysis TEXT,
  source TEXT,
  created_at TIMESTAMP
);

-- 用户档案
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  open_id TEXT UNIQUE,
  name TEXT,
  role TEXT,                    -- UI/平面/产品/UX/品牌
  level TEXT,
  tools JSONB,                  -- Figma/Sketch/PS
  created_at TIMESTAMP
);
```
